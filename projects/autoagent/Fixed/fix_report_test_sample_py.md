## 2. Что исправлено

### ✅ Баг 1 — Закрытие файла
**Было:**
```python
f = open(filename, "w")
f.write(data)
```
**Стало:**
```python
with open(filename, "w") as f:
    f.write(data)
```
> Файл теперь автоматически закрывается при выходе из контекстного менеджера. Утечка ресурсов устранена.

---

### ✅ Баг 2 — Обработка исключений
**Было:**
```python
except:
    pass
```
**Стало:**
```python
except FileNotFoundError:
    logging.warning(f"Файл {filename} не найден, используется конфиг по умолчанию.")
except json.JSONDecodeError as e:
    logging.error(f"Ошибка разбора JSON: {e}")
except Exception as e:
    logging.error(f"Непредвиденная ошибка: {e}")
```
> Теперь каждая ошибка логируется и обрабатывается针对性но.

---

### ✅ Баг 3 — Проверка ключей в словарях
**Было:**
```python
def calculate_total(item):
    return item["price"] * item["quantity"]
```
**Стало:**
```python
def calculate_total(item):
    required_keys = {"price", "quantity"}
    if not required_keys.issubset(item.keys()):
        missing = required_keys - item.keys()
        raise KeyError(f"Отсутствуют обязательные ключи: {missing}")
    return item["price"] * item["quantity"]
```
> Аналогичная проверка добавлена в `process_data`.
