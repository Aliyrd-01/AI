# RAG-пайплайн проекта (локальные заметки)

## Компоненты
- Ingestion: загрузка документов, очистка, чанкинг с перекрытием.
- Embeddings: локальная модель эмбеддингов через Ollama (nomic-embed-text).
- Vector store: Chroma для экспериментов, Qdrant для продового контура.
- Retrieval: top-K поиск, гибрид (dense + BM25), опциональный reranker.
- Generation: LLM получает найденный контекст и отвечает со ссылками на источники.

## Диалоговый режим
- Router определяет режим: direct / search / react.
- ReAct используется для многошаговых запросов (уточнение, повторный поиск).
- История диалога обрезается по токенам, чтобы не раздувать контекст.

## Продакшен
- FastAPI-сервис с эндпоинтами /ask и /health.
- Docker-развёртывание, health-check, логирование запросов.
- Метрики: latency (p50/p95), hit rate, faithfulness, стоимость на запрос.
